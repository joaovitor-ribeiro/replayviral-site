# Site REPLAY.VIRAL

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público chamado `replayviral-site` no GitHub.
2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório (não envie apenas o ZIP).
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço `https://SEU-USUARIO.github.io/replayviral-site/`.

As páginas ficarão em:
- `https://SEU-USUARIO.github.io/replayviral-site/termos-de-uso/`
- `https://SEU-USUARIO.github.io/replayviral-site/politica-de-privacidade/`

## Antes de publicar
Substitua `[INSIRA SEU E-MAIL DE CONTATO]` nos dois arquivos HTML por um e-mail válido. Revise o texto para refletir as práticas reais do canal. Este modelo é inicial e não substitui aconselhamento jurídico.

## Domínio próprio
Para usar `replayviral.com.br`, será necessário configurar o domínio personalizado no GitHub Pages e ajustar os registros DNS no provedor onde o domínio foi comprado. A verificação do domínio no TikTok é uma etapa separada.
